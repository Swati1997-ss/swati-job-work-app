# Swati App — UI Alpha 28

## Reports Expansion

The Reports module is upgraded into a business-wide reporting hub.

### Reports added
- Sales Report
- Purchase Report
- Expense Report
- Job Work Report
- Production Report
- Stock Report
- Receivable / Payable Report
- Staff Report
- Invoice Report

### Filters
Each report supports:
- From date
- To date
- Search
- Today
- Last 7 days
- Last 30 days
- All

### Report summaries
Each report shows:
- Entry count
- Main amount/value
- Outstanding
- Context-specific fourth metric such as Payable, Advance or Available Quantity

### Data sources
Reports use the app's existing operational data:
- Company sales
- Grain/Pulse sales
- Retail sales
- Purchases
- Expenses
- Oil/Grain Job Work
- Oil batches
- Grain/Pulse production
- Stock/costing
- Party ledgers
- Staff
- Saved invoices

This Alpha focuses on in-app reporting and drill-down visibility.
Export/report-file features can be handled separately later.
