# Swati Mini Oil Mill App — UI Alpha 1

## Scope
This release changes the visual shell and navigation only. Business calculations, stored data, sync logic, Oil/Grain workflows and record structures are preserved.

## New UI
- Professional top app bar with hamburger menu, Swati logo and business title.
- Removed the old left-to-right horizontal navigation tabs.
- Added a left navigation drawer containing all main pages.
- Drawer includes online/offline status and UI version.
- Mixed professional theme: Swati maroon + professional blue + white/gray surfaces.
- Cleaner card system, spacing, responsive touch targets and mobile-first layout.
- Reports landing page redesigned into professional card-list style.
- Report category chips for All / Oil / Grain.
- Report cards jump to Summary, Day-wise, Customer and Village report areas.
- Existing report filters, totals and data tables remain functional.
- Removed the two non-working bill toolbar buttons: “PDF ફાઇલ” and “ફાઇલ શેર”.
- Kept “પ્રિન્ટ / PDF” and WhatsApp actions.
