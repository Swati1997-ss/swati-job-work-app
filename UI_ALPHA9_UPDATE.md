# Swati App — UI Alpha 9

## Common Expense Module

Added company-wide expense management with:
- Company / Oil Mill / Grain-Pulse classification
- Common / Job Work / Production unit classification
- Electricity
- Salary
- Daily Labour
- Transportation
- Loading / Unloading
- Cold Storage
- Machinery Repair
- Machinery Parts
- Packaging
- Maintenance
- Fuel
- Other

Each expense records:
- date
- division
- unit
- category
- title
- party/vendor
- amount
- cash/bank payment mode
- optional period and notes
- operator

Saving an expense also posts the money movement to the common Cash or Bank ledger.

Expense History supports division, unit and category filters.
