# Swati App — UI Alpha 26

## Staff / Labour / Attendance

### Staff Master
Each staff member can store:
- Name
- Mobile
- Role / Work
- Salary Type: Daily / Monthly
- Salary Rate
- Joining Date
- Notes

### Attendance
Daily attendance supports:
- Present
- Half Day
- Absent

Only one attendance entry per staff member per date is kept; saving again updates that day.

### Salary / Advance
Staff financial entries support:
- Salary Paid
- Advance Paid
- Cash or Bank/UPI
- Notes

Payments post into the common Expense ledger.

### Salary Position
The app calculates:
- Attendance units
- Earned salary
- Salary paid
- Advance paid
- Salary outstanding

For monthly staff, this Alpha uses an operational 30-day attendance basis.
This can be refined later with payroll rules if needed.
