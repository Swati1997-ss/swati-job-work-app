# Swati App — UI Alpha 25

## Finance Owner Dashboard v2

### Owner Financial Position
The Finance screen now shows:
- Cash
- Bank
- Liquid Money
- Stock Value
- Receivables
- Payables
- Owned Working Assets
- Net Working Position

### Where is my money?
Owner can quickly see money held in:
- Cash
- Bank
- Stock
- Receivables

### Loan / Credit
Borrowing is kept separate from owned money:
- Sanctioned Limit
- Used / Outstanding
- Available Borrowing

### Business Flow Summary
Finance also shows:
- Total Purchases
- Total Expenses
- Sales Outstanding
- Purchase Outstanding

### Costing Integration
Stock Value comes from Alpha 24 Costing / Valuation when available.

This Alpha improves owner decision visibility without treating stock value as liquid money.
