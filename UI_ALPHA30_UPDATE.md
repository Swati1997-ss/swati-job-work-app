# Swati App — UI Alpha 30

## Stabilization / Sidebar Navigation Polish

This Alpha is the first focused stabilization build after Alpha 29.

### Sidebar improvements
- Replaced the small plain caret with a larger rounded chevron control.
- Added a comfortable touch target for Oil Mill and Grain/Pulse expand/collapse.
- Chevron rotates smoothly between collapsed and expanded states.
- Added subtle rounded background and border for clearer interaction.
- Improved expanded submenu hierarchy using a light vertical guide line and small node markers.
- Kept the existing sidebar colors, Gujarati labels, icons and menu order unchanged.

### Scope
This is intentionally a focused UI stabilization update.
No new business module was added.
