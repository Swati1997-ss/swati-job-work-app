# Next Step: Put Alpha 20 on an HTTPS host

The app is now PWA-ready, but installation requires an HTTPS URL.

After hosting:
1. Open the HTTPS app URL on Android Chrome or iPhone Safari.
2. Open Settings → Shared Sync Setup.
3. The Apps Script endpoint is prefilled. Enter the same private Workspace Key once.
4. Save Sync Setup, then Pull Latest.
5. Assign the device to the correct operator.
6. Install/Add to Home Screen.
7. Create one test entry, Sync & Merge, and confirm it appears on another device after Pull Latest.

Do not publish the private Workspace Key in the hosted files. Alpha 20 stores it locally on each trusted device.
