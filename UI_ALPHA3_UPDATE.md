# Swati Mini Oil Mill App — UI Alpha 3

## Customer Flow
- Customers now open as **Village → Customers → Customer Detail**.
- The Customers landing page shows village cards first.
- Opening a village shows only customers from that village.
- Opening a customer shows:
  - village
  - mobile
  - total entries
  - total job-work amount
  - receivable/payable outstanding
  - recent entries
  - quick Oil / Grain entry buttons
- Recent customer entries can be opened directly.

## Drawer / Header Polish
- Smaller Swati branding inside the hamburger drawer.
- Replaced simple character icons with cleaner SVG navigation icons.
- Removed Online/UI Alpha text from the bottom of the drawer.
- Drawer footer now shows the assigned Operator.
- Tapping the Operator footer opens Operator details (name, device ID, online/offline) and allows changing assignment.
- Tapping the Swati logo/name in the top app bar returns directly to Home.
- Tapping the Swati brand inside the drawer also returns to Home.

## Preserved
- Existing business calculations and data structure.
- Oil / Grain workflows.
- Reports and sync.
- Current local records.
