# Swati App — UI Alpha 24

## Costing / Stock Valuation

### New Costing module
The app now calculates an operational inventory valuation view using:
- purchase quantities and purchase values
- production output quantities
- processing expenses
- current available stock

### Per-item costing
Each item shows:
- Available Stock
- Average Purchase Cost
- Processing Cost per Unit
- Estimated Unit Cost
- Estimated Stock Value

### Company totals
The module shows:
- Total Stock Value
- Total Purchase Value
- Total Processing Cost
- Money Tied in Stock

### Finance integration
Finance now prefers the Costing module's Total Stock Value when available.

### Important
This is an operational costing estimate, not a final statutory/accounting valuation model.
The next Finance Alpha can use this improved stock value for the Owner Financial Position.
