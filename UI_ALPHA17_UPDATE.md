# Swati App — UI Alpha 17

## Terminology Correction

The by-product terminology is standardized across the user-facing app:

- English: **Khol**
- Gujarati: **ખોળ**

The previous English term is removed from user-facing:
- selling screens
- stock labels
- reports / summaries
- bilingual interface text
- documentation

Internal code identifiers may still use legacy variable names such as `khaliProduced` where changing them would risk breaking stable logic. These are not shown to operators and do not affect the corrected app terminology.
