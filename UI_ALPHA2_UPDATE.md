# Swati Mini Oil Mill App — UI Alpha 2

## Changes
- Removed “Digital મજૂરી કામ” and branding-helper wording from the app header.
- Removed the “સ્વાતિ મજૂરી કામ” page eyebrow.
- Replaced visible “મજૂરી કામ” wording with the cleaner “મજૂરી” where it appears in UI labels.
- Removed English “Business Intelligence” from Reports.
- Reports use Gujarati naming.
- Report cards now open dedicated report subpages instead of scrolling inside one long page.
- Added separate pages/views for:
  - કુલ સારાંશ
  - દિવસ મુજબ સારાંશ
  - ગ્રાહક સારાંશ
  - ગામ મુજબ સારાંશ
- Each report subpage has its own Back button and keeps the existing date/business filters.
- Removed extra explanatory sentences from Settings sections while preserving the actual controls.
- Operators section remains functional.
- Existing data, calculations, sync logic and stored records are not changed in this UI release.
