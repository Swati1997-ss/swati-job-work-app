# UI Alpha 41

- Removed Quick Owner Links and repeated operation buttons from the main page.
- The centre bottom action now opens Retail Sale, the operator's frequent workflow.
- The bottom-right Tools sheet now contains less-frequent owner and office functions instead of duplicating the hamburger menu.
- Oil sold inside a job-work bill now reduces Processing Unit Groundnut Oil stock.
- Oil Retail is locked to Groundnut Oil and reduces the same Processing Unit stock.
- Grain/Pulse Retail uses a controlled processed-item selector and reduces the selected item's stock.
- Replaced Costing / Valuation with a business-focused Price & Profit planner using raw cost, processing cost, by-product credit, target margin and current selling price.
- Reports now open with graphical sales, job-work, expense, stock and collection analysis.
