# Swati App — UI Alpha 38

Alpha 38 makes the interface shorter and easier to scan without changing business behavior.

## Removed

- Repeated page-introduction sentences.
- Helper captions that restated the section or button title.
- Descriptions below dashboard shortcuts and report-category buttons.
- Redundant history, finance, invoice, stock and customer-list subtitles.

## Preserved

- Field labels, amounts, totals, formulas and dynamic status text.
- Validation messages, stock warnings and quantity-balance warnings.
- Operational guidance that prevents incorrect entries.
- Costing disclaimers, backup/sync guidance and file-action instructions.

## Compatibility

This release contains all Alpha 37 data-integrity, backup, sync, reporting and finance fixes. No stored business-data format was changed.
