# Swati App — UI Alpha 34

## Finance Controls & Setup Fix

Finance is now actionable instead of view-only.

### Added
- Opening Cash setup
- Bank Account add
- Bank Account edit
- Account type: Current / Savings / CC / OD
- Bank opening balance
- Loan / Credit facility add
- Loan sanctioned limit
- Loan used / outstanding
- Bank and loan management lists

### Calculation fixes
- Loan Limit / Used / Available now calculate from saved loan facilities.
- Business Flow Summary now uses the correct purchase and expense totals.
- Finance dashboard refreshes immediately after setup changes.

This is a stabilization fix, not a new unrelated module.
